How this works

On Stremio: "Install everything" opens each addon in turn via a deep link — just tap through the prompts as they pop up. Allow pop-ups for this site if some don't open.

On Nuvio: there's no one-click install. Use "Copy link" on each addon below and paste it into Settings → Addons → Add Addon, one at a time.

Read before picking a stream

This addon covers every quality, 4K down to unknown, and colour-codes each link like a traffic light: green is the best link, orange is okay, red means avoid it, or only use as a last resort. This traffic-light system is only on this addon — the spares below don't have it.

Not on a 4K display? Just skip the links tagged 4K when you're picking a stream.
